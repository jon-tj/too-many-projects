Command-line tool

Your tasks and hours, from the terminal

tmp lists your projects and tasks, creates and moves tasks, and starts and stops time tracking without leaving the terminal. It is a single file that needs Node.js 18 or newer, and AI coding agents can use it too.

1 Make a token

In Settings → API tokens, create a token named after the computer it is for, and copy it: it is only shown once. The token acts as you, so keep it secret. Revoke it there when you no longer use it.

Commands

With AI coding agents

Agents such as Claude Code, Codex or Cursor can run tmp like you do: picking up tasks, marking them done and noting follow-up work. Sign in on the machine the agent runs on, then add a note like this to the project's CLAUDE.md or AGENTS.md: 

{{ agentNote }}

Consider a separate token for each agent, so you can see when it was last used and revoke it on its own. A built-in MCP server is planned.
